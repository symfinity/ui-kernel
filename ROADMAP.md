## Details

### 0.1.x — Foundation

Design tokens, built-in themes, Twig CSS helpers, Flex recipe, Symfony integration

### 0.2.x — DTCG and colour system

W3C design tokens, semantic colour vocabulary, OKLCH palette generation

### 0.3.x — Theme engine

Runtime switching, overlays, capability probe, nested theme inheritance; ui-designer v0.1.0 companion for dev-only theme authoring

### 0.4.x — Token engine

Computed tokens, token references, expressions, validation, normalization

### 0.5.x — Generator engine

Palette, typography, spacing, radius, shadow, and animation generators

### 0.6.x — Contracts

Schema versioning, theme and generator contracts, export, compatibility validation, extension points

### 0.7.x — Tooling

Interactive CLI, diagnostics, inspector, token browser, theme diffing, migration assistant

### 0.8.x — Ecosystem

Font Manager, Icon Manager, UX packages, CMS, design-system presets, shared manifests

### 0.9.x — Hardening

API freeze, performance, documentation, cookbook, migration guides, long-term compatibility

### 1.0.x — Stable API

SemVer-stable configuration, theme and token contracts, extension API, long-term compatibility
